## Resolved follow-up items

- **ML Kit presentation resolved:** every automatic place-name translation now displays Google's official unmodified “Powered by Google Translate” badge. The in-app translation help states that Google Translate powers the feature, provides the required disclaimer and links to Google Translate; the enabling action is labelled accordingly. [Requirements](https://docs.cloud.google.com/translate/attribution).
- **DM-D.S.S notices resolved:** the complete general-user EEW cautions are shown before first account authorization in English, Czech and Japanese. The displayed notice revision is retained locally, and the notice plus official source link remains accessible from the Data source dialog. This is a notice requirement for the permitted per-user client integration. [Cautions](https://dmdata.jp/docs/eew/).

## Private forecast implementation

The owner's publication boundary remains: keep `LocalEewForecastEngine.kt` and its optional inputs out of public Git pending the JMA consultation. This is not a finding that forecast-related source code is automatically illegal. Any future public provision of the private implementation must be assessed on its actual behaviour. [JMA FAQ](https://www.jma.go.jp/jma/kishou/minkan/q_a_s.html).

- Implementation: `app/src/main/java/cz/misa/quakedeck/data/LocalEewForecastEngine.kt`.
- Inputs: `app/src/localForecast/res/raw/jma2001_travel_times.gz` and `local_eew_station_avs30.gz`.
- **Missing engine or either input automatically selects LITE.** Missing optional files do not cause a build failure.
- `-PomitLocalEewForecastEngine=true` or `-PpublicDistribution=true` selects LITE. Otherwise, the complete local implementation enables FULL.
- FULL compilation and an actual missing-input LITE compilation passed during the build-only correction.

JMA2001 table reuse is permitted with attribution. J-SHIS permits private use of the local ground lookup and distribution of processed results, while prohibiting unchanged-data redistribution. The private lookup is excluded from public builds; no permission to publish it is claimed. [JMA terms](https://www.jma.go.jp/jma/kishou/info/coment.html); [J-SHIS Articles 4–5](https://www.j-shis.bosai.go.jp/agreement).

Local history contains earlier wave code in `8b99e37` and input blobs introduced in `e6846b2`. Ignoring files does not remove historical copies. This concerns the requested Git boundary, not an established violation of forecasting law. Remote publication was not checked; no history rewrite was performed.
