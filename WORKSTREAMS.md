## Global ignored-engine continuity rule

This rule applies to **every current and future workstream**. If any workstream
reads and changes
`app/src/main/java/cz/misa/quakedeck/data/LocalEewForecastEngine.kt`, its
continuation record and completion handoff must explicitly remind the user to
manually transfer the updated file to the same project-relative location on the
other QuakeDeck machine. Git cannot synchronize this ignored file. Do not claim
the other checkout or its `FULL` build is current until the user confirms that
manual transfer. If tracked forecast contracts changed too, explicitly require
the transferred engine to be the matching version.
