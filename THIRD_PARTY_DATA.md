# Third-party / public data notes

The [2 September 2026 source-legality audit](outputs/source-legality-audit/2026-09-02/README.md) is the current rights assessment, including unresolved permissions, individual station-source references and resolved software licence declarations. These attribution notes do not certify unrestricted redistribution or authorise forecast provision.

- Japan base geometry: JMA `20190125_AreaForecastLocalM_prefecture_GIS`, preprocessed into a 118,329-byte quantized/delta-encoded gzip resource at approximately 1 km line tolerance. JMA's 64 source records are dissolved into exactly 47 prefectures before simplification; 南鳥島 is deliberately excluded. Source archive SHA-256: `F4E32E21A806120EAC86C529FF9E5ED8130B13AC9E5988C2E8A4A8F4093DDCE0`.
- JMA place-name translations: JMA multilingual dictionary data, preprocessed into the app resource.
- Free earthquake stream: P2PQuake API v2.
- Public-holiday schedule data: downloaded directly from Nager.Date's public yearly API for the automatically detected or manually selected country. The request contains the ISO country code and year, but no carrier, SIM identifier, schedule setting, coordinate, or other location data. The current and following years are cached locally; country-wide and subdivision-scoped public-holiday records are retained, while country-wide dates are currently applied to the schedule.
- Tsunami bulletins: P2PQuake API v2 code `552`, derived from JMA tsunami forecast/warning information.
- Built-in tsunami integration fixture: reconstructed from JMA's published 1 January 2024 Noto Peninsula earthquake and tsunami-warning progression; not a verbatim archived P2PQuake capture.
- Seismic-intensity station catalogue: downloaded directly from the [Japan Meteorological Agency station map](https://www.jma.go.jp/jma/kishou/know/jishin/intens-st/index.html) ([station JSON](https://www.jma.go.jp/jma/kishou/know/jishin/intens-st/stations.json)), joined by exact Japanese name to worksheet 24 of `地震火山関連コード表.xlsx` in the [official JMA XML code tables](https://xml.kishou.go.jp/tec_material.html) ([2026-08-26 archive](https://xml.kishou.go.jp/jmaxml_20260826_Code.zip)). QuakeDeck preserves the published coordinates, station identities, JMA/NIED/local-government operator identities and administrative codes. All 4,360 map stations and all nine fields exactly matched the previous bundle in the [2026-09-02 audit](outputs/jma-station-migration-audit/2026-09-02/README.md). One code-table-only entry, `1336172`, has no map coordinates and is explicitly excluded; the resource represents the complete official map inventory, not the entire historical/code-table inventory. Runtime third-party downloads and cache loading have been removed; future catalogue updates require an offline audit.
- Station-catalogue credit: **Source: Japan Meteorological Agency website. Station map data and official XML code tables processed into the QuakeDeck catalogue by QuakeDeck.** Source links are above and embedded in the resource. Reuse follows [JMA's published terms](https://www.jma.go.jp/jma/kishou/info/coment.html), which adopt [Public Data License 1.0 (PDL1.0)](https://www.digital.go.jp/resources/open_data/public_data_license_v1.0), unless an item states other rights. This is a QuakeDeck adaptation, not an unmodified JMA product. Japanese credit: 出典：気象庁ホームページ「震度観測点」及び「気象庁防災情報XMLフォーマット 技術資料」。QuakeDeckが加工して作成。 The app's Data source dialog and website credits provide the source and terms links; source hashes and processing provenance accompany the bundle.
- EEW travel times: JMA's published `JMA2001` P/S travel-time table, now retained only in the ignored `app/src/localForecast/res/raw/jma2001_travel_times.gz` and included only with the private FULL engine. [Original source](https://www.data.jma.go.jp/eqev/data/bulletin/catalog/appendix/trtime/tjma2001.zip).
- Local EEW ground input: NIED J-SHIS V4 AVS30 station-sampled values, now retained only in the ignored `app/src/localForecast/res/raw/local_eew_station_avs30.gz`. Permission to redistribute this unchanged-value subset is unresolved; selecting records or converting format must not be assumed to satisfy the [J-SHIS redistribution terms](https://www.j-shis.bosai.go.jp/agreement). The generator is `tools/build_local_eew_ground_resource.py`; [API description](https://www.j-shis.bosai.go.jp/api-sstruct-meshinfo).

- Station-name/address research additionally uses the Digital Agency ABR town master, GSI reverse-geocoder results, NIED station metadata, and municipal/prefectural/FDMA/BODIK documents. Source: Digital Agency ABR town master and GSI website, processed by QuakeDeck for locality matching and derived names. [ABR terms](https://www.digital.go.jp/policies/base_registry_address_tos); [GSI terms](https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html). Individual document and dataset conditions remain separate; the audit's station register records every source URL and affected station.
- NICT public NTP supplies the visible JST clock. Normal use is permitted under its [FAQ](https://www.nict.go.jp/en/sts/ntp_faq.html); a process-wide limiter caps send attempts, including failures, at 20 per rolling hour.
- Android Geocoder supplies manual city/postcode lookup through the device's configured service. Google Translate powers optional on-device place-name translation through ML Kit, subject to [ML Kit terms](https://developers.google.com/ml-kit/terms), [ML Kit translation rules](https://developers.google.com/ml-kit/language/translation/translation-terms) and [Google's attribution requirements](https://docs.cloud.google.com/translate/attribution). Automatic results carry Google's official unmodified attribution badge; the in-app translation help provides the required disclaimer and Google Translate link. The bundled official `color-regular@3x.png` and `white-regular@3x.png` badges have SHA-256 `44AAB849963BC32493C1B2FF4ED9D47AEA8D16CDFA12D3AAEBEF22FEB2BA2CA9` and `F5A888A335C107B6CC106E59804D08B5FEB35B3755188B17FFC5E577298E6F1E` respectively.

- Regional geographic context: Natural Earth low-resolution country geometry (public domain), preprocessed into Web-Mercator paths spanning a generous Asia/Pacific navigation envelope around Japan; relevant dateline geometry is duplicated eastward so the Japan-centred camera has continuous context across 180°. Natural Earth's low-detail Japan polygons are removed because QuakeDeck draws Japan from official JMA geometry.
- JMA reporting geometry: official JMA GIS layers `20190125_AreaForecastLocalM_prefecture_GIS`, `20240520_AreaForecastLocalE_GIS`, `20190125_AreaForecastLocalEEW_GIS`, `20240520_AreaTsunami_GIS`, and `20241128_AreaInformationCity_quake_GIS`, preprocessed offline into quantized/delta-encoded gzip resources. These provide the 47-prefecture base, detailed earthquake-reporting areas, public EEW warning areas, tsunami forecast-zone coastlines, and deep-zoom earthquake municipality/designated-city-ward polygons. The municipality resource uses a streamed ZigZag-varint binary payload to minimise both APK size and temporary Android parsing memory.
- The preprocessing scripts are retained in `tools/build_jma_prefecture_base.py` and `tools/build_jma_area_geometry.py`; the original large JMA ZIP archives are not bundled in the source package. Base geometry uses approximately 1 km simplification and 11 m coordinate quantisation; deep-zoom municipality geometry uses approximately 55 m simplification and 11 m coordinate quantisation. Detailed layers remain lazy-loaded.
- Built-in combined Noto integration fixture: reconstructed code `551`/`552`/`554`/`556` sequence based on the published 1 January 2024 Noto earthquake, EEW, and tsunami-warning progression; not a verbatim archived P2PQuake capture.
