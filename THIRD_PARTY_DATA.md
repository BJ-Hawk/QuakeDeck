# Third-party / public data notes

- Japan administrative geometry: MLIT National Land Numerical Information (N03), preprocessed by the project into compact TopoJSON.
- JMA place-name translations: JMA multilingual dictionary data, preprocessed into the app resource.
- Free earthquake stream: P2PQuake API v2.
- Public-holiday schedule data: downloaded directly from Nager.Date's public yearly API for the automatically detected or manually selected country. The request contains the ISO country code and year, but no carrier, SIM identifier, schedule setting, coordinate, or other location data. The current and following years are cached locally; country-wide and subdivision-scoped public-holiday records are retained, while country-wide dates are currently applied to the schedule.
- Tsunami bulletins: P2PQuake API v2 code `552`, derived from JMA tsunami forecast/warning information.
- Built-in tsunami integration fixture: reconstructed from JMA's published 1 January 2024 Noto Peninsula earthquake and tsunami-warning progression; not a verbatim archived P2PQuake capture.
- Initial seismic-intensity station coordinate catalogue: `iku55/jma_int_stations` (GitHub), downloaded and cached by the app. QuakeDeck uses its coordinates plus the published detailed-area code/name to join station observations to the official JMA region geometry. This remains a provisional catalogue layer designed to be swapped for JMA's current station-parameter distribution.

- Regional geographic context: Natural Earth low-resolution country geometry (public domain), preprocessed into Web-Mercator paths spanning a generous Asia/Pacific navigation envelope around Japan; relevant dateline geometry is duplicated eastward so the Japan-centred camera has continuous context across 180°. Natural Earth's low-detail Japan polygons are removed from this resource because QuakeDeck draws Japan separately from the detailed N03-derived geometry.
- JMA reporting geometry: official JMA GIS layers `20240520_AreaForecastLocalE_GIS`, `20190125_AreaForecastLocalEEW_GIS`, `20240520_AreaTsunami_GIS`, and `20241128_AreaInformationCity_quake_GIS`, preprocessed offline into quantized/delta-encoded gzip resources. These provide detailed earthquake/forecast regions, public EEW warning areas, tsunami forecast-zone coastlines, and deep-zoom earthquake municipality/designated-city-ward polygons. The municipality resource uses a streamed ZigZag-varint binary payload to minimise both APK size and temporary Android parsing memory.
- The preprocessing script is retained in `tools/build_jma_area_geometry.py`; the original large JMA ZIP archives are not bundled in the source package. Geometry is simplified and quantised for phone rendering while official area codes and Japanese names are preserved; the deep-zoom municipality layer uses approximately 55 m simplification and 11 m coordinate quantisation. The municipality layer is loaded lazily only after the map passes the current in-map detail threshold (40× by default while tuning).
- N03 prefecture geometry remains the base land layer and fallback when an incoming bulletin name cannot be resolved to an official finer JMA area. At normal zoom it remains visually unchanged; above the current municipality-detail threshold, resolved station observations may replace the broad regional fill with JMA municipality/ward fills.
- Built-in combined Noto integration fixture: reconstructed code `551`/`552`/`554`/`556` sequence based on the published 1 January 2024 Noto earthquake, EEW, and tsunami-warning progression; not a verbatim archived P2PQuake capture.
