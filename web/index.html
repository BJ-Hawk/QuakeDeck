What exists today

A serious map before the serious live feed.

The current Android prototype already displays recent JMA earthquakes, historical events, prefecture shading by observed Shindo, station observations, progressive labels, and event-aware camera controls.

🗾

Detailed Japan map

Prefecture geometry, progressive city and station labels, deep zoom, historical-event focus, and a lightweight regional context layer.

📍

Observed intensities

Current and historical events can color prefectures and reported stations using the JMA seismic-intensity scale.

⚡

DM-D.S.S next

The planned production milestone is browser-based OAuth, reliable WebSocket reception, successive EEW reports, cancellations, and live observations.
