Privacy policy

Last updated: 30 July 2026.

This website is a static project site for QuakeDeck. It does not use advertising, analytics, tracking pixels, or a QuakeDeck-operated user account system.

Normal website use

The hosting provider may process standard technical data such as IP address, browser type, requested files, timestamps, and security logs according to its own policies. QuakeDeck does not receive a dedicated analytics dashboard from this site.

DM-D.S.S capability probe

The optional diagnostic page redirects you to DM-D.S.S for authorization. It requests only the contract.list and socket.list scopes.

After authorization, the page temporarily receives an access token and refresh token in the browser. They are not sent to a QuakeDeck server, written into the generated report, or intentionally stored persistently. The page uses them to request the contract and socket lists, then attempts to revoke both tokens immediately.

The generated report excludes OAuth tokens, client secrets, API keys, socket tickets, and IP addresses. The public OAuth client ID may be remembered in your browser's local storage for convenience.

Third parties

DM-D.S.S processes authorization and API requests under its own terms and privacy policy. The website host processes ordinary web traffic under its own policy.
