Controlled OAuth diagnostic

DM-D.S.S capability probe

This one-time probe reads your visible plans and sockets, then calls Socket Start exactly once for QuakeDeck’s earthquake + EEW stream. It never opens the returned WebSocket. If DM-D.S.S creates a socket ticket, the probe immediately closes that exact socket ID.

Requested scopes: contract.list, socket.list, socket.start, socket.close, telegram.get.earthquake, and eew.get.forecast. Leave JQuake connected for the safest test: the expected useful result is HTTP 409 because its one connection slot is already occupied. Temporary OAuth tokens are revoked after the test.
